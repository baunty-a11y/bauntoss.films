# BAUNTOSS — портфолио

Статичный сайт: интро с папкой, внутри разделы с видео.

## Как добавить видео
Открой `index.html`, найди блок `const SECTIONS = [` (в начале скрипта) и добавь ссылку YouTube в нужный раздел.

- Shorts (`/shorts/`) сами показываются вертикально.
- Обычное видео, снятое вертикально: `{ url: '...', vertical: true }`.
- Подпись: `{ url: '...', title: 'Название' }`.
- Своя обложка: положи картинку в `covers/` и укажи `{ url: '...', cover: 'covers/файл.jpg' }`.

## Файлы
- `assets/intro.mp3` — мелодия интро.
- `vendor/page-flip.browser.js` — библиотека перелистывания (MIT, см. `vendor/page-flip.LICENSE`).
